# Creative Project

## Codebase Health Monitor

Codebase Health Monitor is a web app that connects to a group project’s Git repository and analyses its activity to detect potential problems early. It tracks things like contribution balance between team members, code quality differences, merge conflicts, and signs of growing technical debt. Using statistical analysis and basic anomaly detection, it generates risk warnings and a simple “health score” for the project. The aim is to help student teams and lecturers identify collaboration or codebase issues before they become serious problems, improving fairness, maintainability, and overall project quality.
